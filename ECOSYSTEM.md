# Ecosystem map

`cranium-ai` is the public intelligence interface and host surface for Convertible Cranium. It is a supporting, non-authoritative surface.

## Boundary

This repository may route model requests, retrieve research, present context, and propose responses or actions. It does not grant authority, commit governed state, invoke protected tools, or issue authoritative receipts. Those responsibilities belong to the private `worthwylfoundation-hue/cranium-kernel` repository at the pinned revision recorded in `KERNEL_PIN`.

Cognition may come from anywhere; authority comes only through the Kernel. A private repository may appear as HTTP 404 to logged-out visitors.
